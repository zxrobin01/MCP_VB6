# VB6MCP 工具总览（工具面契约沙箱）

- 来源：docs/tools_schema.json（dump_tools_schema.py 抓取的 live 快照；生成物，勿手改）
- 数量：111

## 使用顺序（工具集/描述变化后，按序执行并原样回贴输出）

```text
python tools/dump_tools_schema.py                        # 1. 抓 live 快照 -> docs/tools_schema.json（默认不碰冻结基线）
python tools/export_tool_catalog.py                      # 2. 重新生成本文件
python tools/check_schema_baseline.py                    # 3. 快照 vs 冻基线 -> schema_changes=0
python tools/check_live_tools.py docs/tools_schema.json  # 4. 独立交叉验证 -> ORDER_MATCH=True
python tools/mcp_strict_audit.py                         # 5. 严格 schema 审计 -> strict_failures=0
```

## 冻结件与授权前提

- `tools/schema_baseline.json` 是**冻结件**：dump 默认**不写**它；只有显式 `--freeze` 才写，且必须**先经 `contract` 广播**（S 主卡 + 每个受影响进程确认卡 + 版本号递增）。
- 禁止为了得到 `schema_changes=0` 就 `--freeze`——那会让基线比对退化为恒真（缺陷 REQ-20260921-008）。
- 数据源以 `docs/tools_schema.json`（live 快照）为准；**不要**解析 `integration/CodeTools.cls`（沙箱副本会滞后，曾致数量失真 REQ-20260922-011）。
